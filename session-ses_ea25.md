## Анализ проекта FluidDial для расширения портов

### Текущее состояние

**Плата:** ESP32 (оригинальный WROOM, не S3)
**Дисплей:** 3248S035 (320x480) с резистивным тачем XPT2046

**Использованные пины:**
- SPI (дисплей + тач): 12, 13, 14, 15, 33
- Энкодер: 22, 23
- LED/кнопки: 4, 5, 16, 17, 18, 19
- Backlight: 27
- UART к FluidNC: 1 (TX), 3 (RX)

**Свободные пины:**
- **GPIO 0** — boot strapping (должен быть HIGH)
- **GPIO 34, 35, 36, 37, 38** — input-only (без внутренних подтяжек)

**Критическая проблема:** У тебя осталось **крайне мало** свободных пинов. GPIO 34-38 — input-only, что ограничивает их использование.

---

### Рекомендации по модулям расширения

#### Вариант 1: I2C GPIO Expander — **PCF8574** или **MCP23017** (Рекомендую)

**Почему I2C:**
- Использует всего **2 пина** (SDA=GPIO 21, SCL=GPIO 22) — НО! GPIO 22 уже занят энкодером. Нужно перенести энкодер на другие пины.
- Альтернатива: использовать встроенный I2C ESP32 на пинов 21/22, переназначив энкодер на GPIO 34/35 (input-only, но для энкодера это ок — он только читает сигналы)

**PCF8574** (8-bit, I2C):
- Цена: ~$1-2 (модуль с адаптером)
- Каждый чип = 8 входов/выходов
- Адреса настраиваются перемычками (0x20-0x27)
- Можно каскадить до 8 чипов = 64 пина
- **Минус:** только digital I/O, нет аналоговых входов

**MCP23017** (16-bit, I2C, рекомендуемый):
- Цена: ~$2-3
- 16 пинов на чип
- Может работать как вход И как выход одновременно
- Прерывания (INTA/INTB) — полезно для кнопок
- Лучше для кнопок и галетных переключателей

**Что можно подключить через 1-2 чипа MCP23017:**
- Галетный переключатель оси (3-4 позиции = 3-4 пина)
- Галетный переключатель шага (3-4 позиции = 3-4 пина)
- Кнопки (5-8 пинов)
- **Итого:** 2 чипа MCP23017 покрывают всё

---

#### Вариант 2: SPI GPIO Expander — **MCP23S17**

- Аналог MCP23017, но через SPI
- Использует те же SPI пины (12, 13, 14) + новый CS
- **Плюс:** быстрее I2C, не конфликтует с устройствами I2C
- **Минус:** занимает доп. CS пин (можно использовать GPIO 0 или 34)

---

#### Вариант 3: Комбинированный подход (Наилучший)

**Для кнопок и галетных переключателей:**
- **MCP23017** по I2C (GPIO 21/22)
- 1 чип = 16 пинов
- Галетный переключатель оси: 4 пина (4 позиции)
- Галетный переключатель шага: 4 пина (4 позиции)
- Кнопки: 8 пинов (вперёд/назад, подтверждение, отмена и т.д.)
- **Итого:** 16 пинов, 1 чип хватает

**Для джойстика Xbox:**
- **Не через GPIO!** Джойстик Xbox (или любой USB Gamepad) подключается через **USB OTG**
- ESP32 поддерживает USB Host (через библиотеку `ESP32USBHost` или `XboxUSB`)
- Нужен переходник **USB-C/USB-A Female OTG**
- Джойстик будет определяться как HID устройство
- Библиотеки: `XboxUSB`, `ESP32_USBHost_library`

**Альтернатива для джойстика:**
- Bluetooth Gamepad (любой Xbox/PS4/Switch Pro)
- ESP32 поддерживает Bluetooth Classic/HID Host
- Не нужен OTG кабель, просто сопряжение

## Анализ подключения аналогового джойстик-стика

### Что такое аналоговый стик

Стандартный джойстик (как от Xbox контроллера) — это модуль на PCB:
- **2 переменных резистора** по 10kΩ (оси X и Y)
- **1 тактовая кнопка** (подтяжка + сигнал)
- Выходы: VCC, GND, VR_X (аналог), VR_Y (аналог), SW (цифровой)

### ADC пины на ESP32 (CYD 3248S035)

ESP32 WROOM имеет **8 ADC каналов**, но не все доступны:

| Пин | ADC | Статус | Примечание |
|---|---|---|---|
| **GPIO 34** | ADC1_CH6 | **Свободен** | Input-only, без подтяжек |
| **GPIO 35** | ADC1_CH7 | **Свободен** | Input-only, без подтяжек |
| **GPIO 36** | ADC1_CH4 / ADC2_CH0 | Свободен | Input-only |
| **GPIO 37** | ADC1_CH5 / ADC2_CH1 | Свободен | Input-only |
| **GPIO 38** | ADC1_CH6 | **Свободен** | Input-only |
| **GPIO 39** | ADC1_CH5 | **ЗАНЯТ** | Батарея (делитель 1534/1000) |

**Важно:** ADC2 (пины 36-37) **нельзя использовать при включённом WiFi** — ESP32 не может работать с WiFi и ADC2 одновременно.

### Рекомендация по подключению джойстика

**Идеальный вариант — напрямую к ESP32, без дополнительных модулей:**

| Выход джойстика | Подключение к ESP32 | Назначение |
|---|---|---|
| VCC | 3.3V | Питание |
| GND | GND | Земля |
| VR_X | **GPIO 34** (ADC1) | Ось X |
| VR_Y | **GPIO 35** (ADC1) | Ось Y |
| SW | **GPIO 0** + подтяжка 10k к 3.3V | Кнопка |

**Почему GPIO 34/35:**
- Используют **ADC1** — работают одновременно с WiFi
- Разрешение ADC ESP32: 12-bit (0-4095), для джойстика этого более чем достаточно
- Диапазон: ~100-3900 (центр = ~2000)

### Программная реализация джойстика

**Чтение осей:**
```cpp
// Инициализация
analogSetPinAttenuation(GPIO_NUM_34, ADC_11db);  // полная диапазон
analogSetPinAttenuation(GPIO_NUM_35, ADC_11db);

// Чтение (каждые 10-20мс)
int joystick_x = analogRead(GPIO_NUM_34);  // 0-4095
int joystick_y = analogRead(GPIO_NUM_35);  // 0-4095
bool joystick_btn = !digitalRead(GPIO_NUM_0); // LOW = нажата
```

**Логика джойстика:**
```cpp
// Мёртвая зона (дрift центра)
const int DEADZONE = 150;
bool axis_moved = false;

int dx = joystick_x - 2048;
int dy = joystick_y - 2048;

if (abs(dx) > DEADZONE || abs(dy) > DEADZONE) {
    axis_moved = true;
    // dx, dy — вектор направления и силы отклонения
    // масштабируешь под скорость джогинга
}
```

**Интеграция с MultiJogScene:**
- Если джойстик отклонён > мёртвой зоны → игнорировать тач
- Вектор (dx, dy) определяет ось и направление
- Сила отклонения = скорость (как в MPG режиме)
- Кнопка джойстика = подтверждение / пауза

## Про декодеры

**Декодер (демultiplexer)** — микросхема, которая сокращает количество пинов.

**Пример:** Галетный переключатель на 4 позиции — это 4 провода, каждый в отдельный пин. С декодером 2-4 (74HC139):
- 4 позиции → кодируются в **2 бинарных сигнала** (00, 01, 10, 11)
- 2 пина вместо 4
- Декодер превращает 2 бита обратно в "позиция 1 активна", "позиция 2 активна" и т.д.

Для 5 позиций нужен декодер 3-8 (74HC138) — 3 пина вместо 5.

**Но это опционально.** MCP23017 имеет 16 пинов, их хватит и без декодеров (12 из 16 займётся, 4 останется).

## Главный вопрос: производительность

Посмотрел код — вот что важно:

### Как устроен ввод сейчас

`onPoll()` в `MultiJogScene.cpp` (строка 784) — это **основной цикл опроса**, который вызывается каждый кадр рендеринга. Там уже сейчас:
- Опрос энкодера (через прерывания, не в poll)
- Проверка flow control для джогинга
- Отправка команд на станок

**Всё неблокирующее** — никаких `delay()`, только `millis()` для таймингов.

### I2C (MCP23017) — не будет тормозить

- Чтение 16 пинов = **2 байта данных**
- На 100kHz (стандарт I2C): **~0.2 мс** на всё чтение
- На 400kHz (fast mode): **~0.05 мс**
- Сравни: `MPG_INTERVAL_MS = 30мс` — интервал между командами джогинга

**0.2мс против 30мс — это 0.6% нагрузки. Пренебрежимо.**

### ADC (джойстик) — не будет тормозить

- `analogRead()` на ESP32: **~0.1-0.2мс** на канал
- 2 оси X+Y = **~0.2-0.4мс**
- GPIO 34/35 используют **ADC1** — работают **параллельно с WiFi** (в отличие от ADC2, который конфликтует с WiFi)

**0.4мс против 30мс — тоже 1.3% нагрузки.**

### Интеграция — всё в том же onPoll()

```cpp
void onPoll() override {
    // Текущий код (не меняется)
    if (dynamic_jog_active()) {
        service_mpg();
    } else {
        precise_flush();
    }
    
    // + Чтение MCP23017 (0.2мс)
    uint16_t mcp_state = mcp.readGPIOAB();
    int new_axis_switch = decode_gal_axis(mcp_state);
    int new_step_switch = decode_gal_step(mcp_state);
    
    // + Чтение джойстика (0.4мс)
    int joy_x = analogRead(GPIO_NUM_34);
```

## Assistant



Да, это **MCP23017** — именно тот модуль, который я рекомендовал.

Вижу все ключевые элементы:

| Элемент | Назначение |
|---|---|
| **PA0-PA7, PB0-PB7** | 16 пинов GPIO |
| **SDA, SCL** | I2C шина |
| **A0, A1, A2** | Адресация (можно 8 чипов на одной шине) |
| **INTA, INTB** | Прерывания (мгновенная реакция на кнопки) |
| **Чип в центре** | MCP23017 |

### Подходит ли?

**Да, идеально.** Но есть нюанс — посмотри на резисторы подтяжки.

На плате уже есть **резисторы 10k** на SDA и SCL (маленькие чёрные прямоугольники рядом с SDA/SCL). Это значит:
- **Не нужно допаивать** внешние резисторы подтяжки
- Можно сразу подключать к ESP32

### Подключение к CYD 3248S035

| Пин модуля | Пин ESP32 | Провод |
|---|---|---|
| VCC | 3.3V | Красный |
| GND | GND | Чёрный |
| SDA | GPIO 21 | Зелёный |
| SCL | GPIO 22 | Жёлтый |
| A0, A1, A2 | GND (адрес 0x20) | Не подключать, если 1 чип |
| INTA | **не подключать** (опционально) | — |

### Библиотека

`Adafruit_MCP23017` — стандартная, лёгкая, ~2KB RAM.

```cpp
#include <Adafruit_MCP23017.h>
Adafruit_MCP23017 mcp;

// Инициализация
mcp.begin(0x20);  // адрес 0x20 (A0-A2 на GND)

// Настройка пинов на вход
mcp.pinMode(0, INPUT);  // галетный ось позиция 1
mcp.pinMode(1, INPUT);  // галетный ось позиция 2
mcp.pinMode(2, INPUT);  // галетный ось позиция 3
mcp.pinMode(3, INPUT);  // галетный ось позиция 4
mcp.pinMode(4, INPUT);  // галетный шаг позиция 1
// ... и т.д. до 15

// Чтение в onPoll()
uint16_t state = mcp.readGPIO();
bool axis_pos1 = state & (1 << 0);
bool axis_pos2 = state & (1 << 1);
// ...
```

### Итог

Бери, подходит на 100%. Это стандартный breakout для MCP23017, который используют в Arduino/ESP32 проектах.
